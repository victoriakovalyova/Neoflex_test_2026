# AI-классификатор обращений поддержки

Классификация тикетов службы поддержки (**technical / billing / complaint / other**) на базе предобученной **RuBERT-модели** без необходимости обучения. Готовое решение для быстрого запуска MVP.

***

## Возможности

- ✅ Классификация текстов обращений «на лету»
- ✅ Готовый синтетический датасет (50 примеров)
- ✅ Работа без этапа обучения — используется предобученная модель
- ✅ FastAPI-эндпоинт для интеграции
- ✅ Задержка <2 с на CPU
- ✅ Docker-контейнер для развёртывания

***

## Быстрый старт

### Вариант 1: Docker (рекомендуется)

```bash
# Сборка образа
docker build -t support-classifier .

# Запуск контейнера
docker run -p 8000:8000 support-classifier

# Тест API
curl -X POST "http://localhost:8000/classify?text=У%20меня%20сломался%20личный%20кабинет"
```

### Вариант 2: Локально

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск API
uvicorn app:app --host 0.0.0.0 --port 8000

# Тест в браузере или через curl
curl -X POST "http://localhost:8000/classify?text=Почему%20списали%20500%20руб%20за%20подписку?"
```

## API

### POST `/classify`

**Параметры:**
- `text` (query string) — текст обращения

**Пример запроса:**
```bash
curl -X POST "http://localhost:8000/classify?text=Ужасный%20сервис,%20уже%207%20дней%20жду%20ответа!"
```

**Пример ответа:**
```json
{
  "label": "complaint",
  "confidence": {
    "technical": 0.05,
    "billing": 0.08,
    "complaint": 0.82,
    "other": 0.05
  },
  "raw_probs": [0.05, 0.08, 0.82, 0.05]
}
```

## Датасет

Файл `support_tickets_50.csv` содержит 50 синтетических примеров в формате:

```csv
text,labels
"У меня сломался личный кабинет, не могу войти!",technical
"Почему списали 500 руб за подписку?",billing
"Ужасный сервис, уже 7 дней жду ответа!",complaint
"Спасибо за помощь, всё работает!",other
```

Для продакшена замените на реальные размеченные тикеты из вашей системы поддержки.

## Требования

- Python 3.11+
- Docker (опционально, для контейнеризации)

***

## Как это работает

1. Текст обращения токенизируется через RuBERT-токенизатор
2. Предобученная модель выдаёт вероятности по 4 классам
3. Выбирается класс с максимальной вероятностью
4. Ответ возвращается в формате JSON
